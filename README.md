# Crossword English Adventure

Game teka-teki silang bahasa Inggris berbasis HTML, CSS, dan JavaScript.

## Menjalankan

Buka `index.html` langsung di browser atau jalankan server lokal:

```powershell
python -m http.server 5500
```

Kemudian buka `http://localhost:5500`.

## Fitur

- Enam level kosakata bertema
- Sistem level terkunci
- Grid crossword interaktif
- Petunjuk Across dan Down
- Hint, reset, timer, dan skor
- Bintang dan progres tersimpan di `localStorage`
- Tampilan responsif untuk desktop dan perangkat mobile
